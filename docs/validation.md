# 验证范围

自动验证覆盖身份与配对、TLS 固定身份、报文大小和时效、观察与交接状态机、离线恢复、静音租约、通知 payload、更新 URL 校验及构建配置隔离。执行方式见 [开发与测试](../scripts/README.md)。

测试通过只说明对应自动化用例通过，不等价于所有设备或后台状态可用。

## 仍需实机验证

- 真实息屏、深睡、关机、崩溃与用户停止后的行为。
- 厂商后台限制、权限撤销、蓝牙和网络变化。
- 不同播放器的起播识别、暂停能力和声音外放窗口。
- 不同耳机型号及 Mac / Android 组合的路由结果。
- 长时间运行、耗电，以及 Mac 正常退出时的耳机归还。

提交诊断材料前遮蔽个人设备名称、蓝牙地址、局域网地址、媒体内容与配对材料。不要上传配对二维码或运行时密钥。
